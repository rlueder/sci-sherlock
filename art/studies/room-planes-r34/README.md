## Repeatable process

1. Build physical planes with `build-guides.py` in Blender 4.5 LTS. The camera is
   level and frontal: 45 mm, 36 mm sensor, height 3.071698 m, shift Y -0.375.
   Export 320×200 at vertical pixel aspect 1.2. Actor scale is feetY / 176.
2. Paint original room variants with built-in OpenAI ImageGen, using our own earlier
   room artwork and the Blender guide. Exact prompts and generated masters are in
   `generated/`. The first workshop source had an angled window: the targeted
   `workshop-fit-prompt.txt` pass made its uprights and crossbars frontal.
3. Run `convert.ts`: centre-sampled nearest-neighbour reduction and weighted RGB
   palette mapping (2R² + 4G² + B²), the same 64-colour palette as r33. No smoothing,
   dithering or extra colours. `guides/style-conversion.json` records the inputs.
4. Reproject the existing approved rigid clock via `build-clock.py` and `clock.ts`.
   `guides/clock-check.json` checks the fixed hinge, closed master alignment and bounds.
5. Run `build.ts` to extract measured masks, create lamp flicker, export native views,
   generate layered Pixelorama 1.2.3 projects and compose review proofs.
6. Verify each `.pxo` through the actual Pixelorama exporter, compare decoded pixels,
   then losslessly compress the review GIFs. Inspect the result at native scale and
   at the 960×720 nearest-neighbour review scale.

Open-source Blender, Pixelorama and TypeScript handle construction and export.
ImageGen is a proprietary painting step, not an open-source tool. Retained paint
sources can instead be edited manually in Pixelorama without changing the export contract.
No television or third-party game artwork is included.

## Rebuild from the repository root

```sh
# Set BLENDER_BIN and PIXELORAMA_BIN to your installed open-source applications.
"$BLENDER_BIN" -b --python art/studies/room-planes-r34/build-guides.py -- street
"$BLENDER_BIN" -b --python art/studies/room-planes-r34/build-guides.py -- workshop
"$BLENDER_BIN" -b --python art/studies/room-planes-r34/build-guides.py -- stair
"$BLENDER_BIN" -b --python art/studies/room-planes-r34/build-clock.py
node --import tsx art/studies/room-planes-r34/convert.ts
node --import tsx art/studies/room-planes-r34/clock.ts
node --import tsx art/studies/room-planes-r34/build.ts
node --import tsx art/source/verify-study-native.ts art/studies/room-planes-r34
node --import tsx art/source/compress-study-gifs.ts art/studies/room-planes-r34/review
pnpm art check art/studies/room-planes-r34/art.json
pnpm typecheck
```

The generator inputs are retained rather than regenerated by these commands.
Blender geometry and final painting are not pixel-identical. `guides/{room}.json`
records the blockout; `build.ts` and its exported mask PNGs record the painted fit.

## Engineer handoff

`guides/handoff.json` is the measured placement contract: room polygons, arrivals,
interaction approach points, hotspots, layer priorities, prop anchors and timing.
All rooms use `perspective: { horizon: 0, fullSize: 176 }`.

| Resource | Delivery |
|---|---|
| Pictures 101–103 | Opaque base plus exact duplicate foreground/occlusion layers |
| View 221 | Eight 88×168 clock cels; anchor [60,150]; world [292,150]; 150 ms per cel |
| View 220 | Workshop lamp, six full-canvas transparent overlays; [0,0]; priority 130 |
| View 226 | Street/cab lamps, six full-canvas transparent overlays; [0,0]; priority 148 |
| Views 227/228 | Existing filings and scratches, copied with unchanged pixels |

The picture 102 base contains the revealed passage; place view 221 cel 0 to close it.
`export/workshop-closed.png` is an art proof, not the interactive base. All supplied
full-canvas lamp overlays must be unscaled and placed at [0,0]; they replace the
previous small-canvas placement contract. Lamp timing is 200 ms per cel.

The walking band stays at y160–195. No player walks in the workshop recess, road,
far houses or below the stair landing. Five foreground scale checks are supplied
for each room, with one rear check each for street/workshop: 17 total. Native master
pixels and proportions are unchanged. The stair proof uses the approved side master;
a final back-facing performance is still a character task. Horizontal proofs translate
that standing pose, not a walking cycle.

Before game integration, move script interaction points to the proposed approaches
and confirm reach timing against the clock. Old workshop rain/weather/mouse and
pendulum overlays are tied to the old background: do not carry them over without
refitting their masks and checking the new layers. The new backgrounds and included
props are ready for visual review; that atmosphere migration remains separate work.
